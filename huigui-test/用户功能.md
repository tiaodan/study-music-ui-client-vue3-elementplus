# 用户功能回归测试

## 登录注册

| 功能点 | 操作步骤 | 期望行为 |
|-------|---------|---------|
| 用户名登录 | 输入用户名和密码，点击登录 | 登录成功，显示用户信息 |
| 邮箱登录 | 输入邮箱和密码，点击登录 | 登录成功，显示用户信息 |
| 注册 | 填写注册信息，点击注册 | 注册成功，自动登录 |
| 登录失败 | 输入错误密码 | 提示登录失败信息 |

## 个人信息

| 功能点 | 操作步骤 | 期望行为 |
|-------|---------|---------|
| 查看个人信息 | 登录后进入设置页面 | 显示当前用户信息 |
| 修改用户名 | 修改用户名，保存 | 用户名更新成功 |
| 修改性别 | 选择性别，保存 | 性别更新成功 |
| 修改生日 | 选择生日日期，保存 | 生日更新成功 |
| 修改签名 | 修改签名内容，保存 | 签名更新成功 |
| 修改地区 | 选择地区，保存 | 地区更新成功 |
| 上传头像 | 上传新头像图片 | 头像更新成功 |

## 收藏功能

| 功能点 | 操作步骤 | 期望行为 |
|-------|---------|---------|
| 收藏歌曲 | 点击播放栏收藏按钮（爱心） | 收藏成功，按钮变为红色 |
| 取消收藏 | 点击已收藏的歌曲取消收藏 | 取消收藏成功，按钮恢复灰色 |
| 查看收藏列表 | 进入个人收藏页面 | 显示已收藏的歌曲列表 |
