# 回归测试说明

## 目的

每次修改代码后，执行回归测试，确保UI核心功能没有被改错。

## 使用方法

1. 修改代码后，启动开发服务器 `npm run serve`
2. 按模块依次验证测试点
3. 每个测试点：执行操作步骤 → 检查是否符合预期结果
4. 发现问题及时修复

## 模块清单

| 文件 | 模块 |
|-----|------|
| [播放功能.md](播放功能.md) | 播放器核心功能 |
| [歌手模块.md](歌手模块.md) | 歌手列表、详情、筛选 |
| [排行榜模块.md](排行榜模块.md) | 推荐榜单、榜单歌曲 |
| [搜索功能.md](搜索功能.md) | 歌曲/歌单搜索 |
| [用户功能.md](用户功能.md) | 登录注册、个人信息 |
| [其他功能.md](其他功能.md) | 导航、刷新、缓存 |

## 快速验证流程（推荐顺序）

1. **播放功能** - 最核心，优先验证
2. **歌手模块** - 常用功能
3. **排行榜模块** - 新增功能
4. **其他功能** - 基础功能
