# 歌手模块回归测试

## 歌手列表

| 功能点 | 操作步骤 | 期望行为 |
|-------|---------|---------|
| 歌手列表加载 | 进入歌手页面 | 显示歌手列表，每个歌手有头像、姓名 |
| 分页 | 滚动到底部或点击分页按钮 | 显示下一页歌手 |

## 歌手筛选

| 功能点 | 操作步骤 | 期望行为 |
|-------|---------|---------|
| 地区筛选-全部 | 选择"全部"地区 | 显示所有地区歌手 |
| 地区筛选-内地 | 选择"内地"地区 | 只显示内地歌手 |
| 地区筛选-港台 | 选择"港台"地区 | 只显示港台歌手 |
| 性别筛选-全部 | 选择"全部"性别 | 显示所有性别歌手 |
| 性别筛选-男 | 选择"男" | 只显示男歌手 |
| 性别筛选-女 | 选择"女" | 只显示女歌手 |
| 性别筛选-组合 | 选择"组合" | 只显示组合歌手 |
| 字母筛选-全部 | 选择"全部"字母 | 显示所有字母开头的歌手 |
| 字母筛选-特定字母 | 选择"A"字母 | 只显示A字母开头的歌手 |
| 组合筛选 | 选择"内地"+"女"+"A" | 显示符合条件的歌手 |

## 歌手详情

| 功能点 | 操作步骤 | 期望行为 |
|-------|---------|---------|
| 进入歌手详情 | 点击歌手卡片 | 进入歌手详情页，显示歌手信息 |
| 歌手信息 | 查看详情页左侧 | 显示歌手头像、基本资料、简介 |
| 专辑Tab | 点击"专辑"Tab | 显示歌手专辑列表 |
| 专辑切换 | 点击某个专辑 | 显示该专辑歌曲列表 |
| 返回专辑列表 | 点击"返回专辑列表"按钮 | 返回专辑列表视图 |
| 歌曲Tab | 点击"歌曲"Tab | 显示歌手所有歌曲列表 |

## 歌手歌曲播放

| 功能点 | 操作步骤 | 期望行为 |
|-------|---------|---------|
| 专辑歌曲播放 | 双击专辑中歌曲 | 歌曲开始播放 |
| 歌曲Tab歌曲播放 | 双击歌曲Tab中歌曲 | 歌曲开始播放 |
| 添加到播放列表 | 点击歌曲添加按钮 | 添加到播放列表 |
